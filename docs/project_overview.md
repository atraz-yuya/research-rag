# プロジェクト概要

## 目的

研究資料として使用するPDFをローカル環境で検索し、資料の内容に基づく回答と、その根拠を確認できるRAGアプリケーションを開発する。

## 想定ユーザー

論文や技術資料などのPDFから必要な情報を探し、回答の根拠となるページと文章を確認したい研究者、学生、技術者を想定する。

## 最低成功条件

テキストを含む1つ以上のPDFから名前付き資料セットを作成し、質問すると、資料に基づく回答に加えて根拠となるPDF名、1始まりのページ番号、類似度、文章が表示されること。資料セットは再起動後も利用でき、元PDFの変更や欠落を確認できること。

## 現在のMVPの位置付け

CLI版MVPに加え、PySide6 GUI、複数PDFの横断検索、SQLite schema v3による永続資料セット、文書変更検出、macOS packagingまで実装済みである。v0.1.0 release candidateは`PASS WITH KNOWN LIMITATIONS`で、現在は初回ユーザー向けdocumentationと最終release準備の段階にある。Ollamaは別途必要で、OCRや会話履歴はv0.1.0の対象外である。
