# プロジェクト概要

## 目的

研究資料として使用するPDFをローカル環境で検索し、資料の内容に基づく回答と、その根拠を確認できるRAGアプリケーションを開発する。

## 想定ユーザー

論文や技術資料などのPDFから必要な情報を探し、回答の根拠となるページと文章を確認したい研究者、学生、技術者を想定する。

## 最低成功条件

テキストを含む1つのPDFと質問を指定すると、PDFの内容に基づく回答に加え、根拠となるPDF名、1始まりのページ番号、文章が表示されること。

## 現在のMVPの位置付け

現在のMVPは、将来のGUI化や複数資料対応に先立ち、単一PDFをCLIで処理する最小の一連のRAG処理を成立させる段階である。OCR、複数PDF、永続化、クラウドLLMなどは対象外とし、ローカル環境で動作する基本経路の検証に集中する。
