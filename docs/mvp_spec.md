# CLI版MVP仕様

## MVPの対象

- テキストを含む単一PDF
- CLI上での操作
- PDFからページ単位で文章を取得する
- 利用者に表示するページ番号は1始まりとする
- 1つのチャンクが複数ページをまたがないようにする
- 質問に関連するチャンクを検索する
- 検索結果をローカルLLMへ渡して回答を生成する
- 回答とともにPDF名、ページ番号、根拠文章を表示する

## MVPの対象外

- OCR
- スキャン画像のみのPDF
- 複数PDF
- SQLite
- PySide6 GUI
- 会話履歴
- FAISSまたはChromaによる永続化
- クラウドLLM
- LangChain
- LlamaIndex

## エラーとして扱うもの

- 指定したPDFが存在しない
- 指定したPDFを開けない
- PDFから文章を抽出できない
- 質問が空文字である
- Ollamaが起動していない
- 指定したモデルが利用できない

## MVPの完了条件

1つのPDFを指定して質問を入力すると、PDFの内容に基づく回答と、根拠となるPDF名、ページ番号、文章が表示されること。

## 後続Issueで決定する事項

次の値は現時点では固定せず、それぞれの機能を実装する後続Issueで事前に決定する。

- チャンクサイズ
- チャンクのオーバーラップ
- 検索件数
- 埋め込みモデル名
- 生成モデル名
